Install the Chattrn package

Have your developer run these in the Laravel app's root, in order.

1
Add the package
composer require chattrn/connector
2
Run the installer
php artisan chattrn:install
3
Connection token (single-use, expires in 30 minutes) Paste this as a line in the app's .env file. Keep it private.
Generate a token to continue…
4
Map the models Asks which Eloquent models are Product, Variant, Order and Customer, then registers with Chattrn.
php artisan chattrn:map

Connect a custom website

Connect your own ecommerce website through its API. Products, stock and orders then work in Skills, Actions, the AI Agent, the widget and the inbox, just like a Shopify store. Nothing is saved, and only GET requests are sent.

Your endpoints

Add the endpoints you already have. Chattrn calls each once to read a sample; nothing in your store changes. Use :name for values the tester fills in.

Reads pages 1 to N of the product list, so the full count comes back.

Create order, cancel order and cart price check are not tested here, because they change data in the store or need a signed-in customer.

Ask about a product or stock

Ask in your own words. Words in the question are matched against every loaded product. Each match is read again from the API for the zone or outlet, so you see price and availability there.
